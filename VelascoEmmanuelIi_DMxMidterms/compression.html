Compression

What is Compression?

Compression is the process of reducing the size of a file or a group of files to take up less storage space. It uses algorithms to encode them more efficiently and smaller while not losing their essential content. Through compression, it makes sharing files, especially large ones, easier.

Some common compression formats include .zip, .rar, and .jpeg.

While compression can make files smaller, compressing it too much can cause the file quality, especially audio, to lessen.

RLE Algorithm

What is RLE?

Run Length Encoding, or RLE, is a type of compression algorithm. It is usually used for storing data with long sequences of repeated characters.

How to do RLE?

To encode an image with RLE, look at it one row at a time, from left to right. Count how many pixels of the same color sit next to each other, then write that count followed by the color. In the pixel image above, B is blue, Y is yellow, W is white, and G is green.

Row 1 is all blue, so it becomes 8B. Row 2 goes 1 blue, 2 yellow, 3 blue, 1 white, and 1 blue, so it becomes 1B 2Y 3B 1W 1B. Rows 6 to 8 are all green, so each of them becomes 8G. Every time the color changes, a new run starts. Doing this for every row gives the encoded image above.

The long runs shrink the most. The green rows describe 8 pixels with just 2 characters. Row 2 has five runs, so it needs 10 characters to describe 8 pixels, which is longer than the original row.

This is why RLE works best on data with long runs of the same value, such as simple images with large flat areas. When the data has few repeats, the encoded version can be longer than the original, just like ABC becoming 1A1B1C.
